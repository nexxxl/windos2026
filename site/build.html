02 / 应用长什么样

一个目录，
一份清单，
没有打包格式。

入口是 index.html，元信息在 app.json。运行时没有签名包，也没有专有格式； 复制、备份、删除都是文件操作。

app.json · 最小字段
{ "id": "focus-timer", "name": "番茄钟", "description": "25 分钟专注计时", "entry": "index.html", "capabilities": ["storage"] }
边界 正文 ≤ 250 行、产物 ≤ 2 MiB、生成超时 180 秒；不允许外部 http(s) 资源，声明 storage 才有本地存储。

两类产物

复刻型 Web 应用（网页、小游戏、桌面应用形态）与空间交互型应用（Three.js 3D 镜头、互动影游、透视错觉）。

验收不靠一句「好了」

截图对比与自检是门禁；HTTP 200 或模型回答都不能单独证明业务成功。

现在的状态

试验田有历史构建到安装的验证记录；正式移植、真实成功率与版本迁移还没验收。

04 / 宿主兼容

同一台桌面，
接到别的宿主里。

当前 @nexlos/os 是 DSH 专用插件。要接到 VS Code、Codex、OpenClaw、Goose，需要分别适配并各自验收。

宿主需要的适配状态
DSH插件包 + Host/Client 插槽已发布 v1.1.1-lite.0
Octop命令版：ctx shim + 独立服务 + 导航注入已交付
VS Code完整桌面 VSIX + 通用 MCP 工具包计划首批
Codex引擎适配验证计划首批
OpenClaw / OpenCode / Goose锁版本实验轨道待评估

宿主兼容性结论来自 2026-11-12 的接口与本地源码核验；尚未开发或发布海外宿主适配器。
