## 边界

独立性指构建、测试、打包和运行所需文件均在本目录或明确的外部宿主依赖中，不意味着两版功能等价。DSH 会话、模型、PTY、Chromium/WebRTC 及完整 Client 交互未在这次拆分中重新验收；Windows/Linux 实机结果仍以各自平台记录为准。插件的伴侣安装、部分高级办公和真实恢复机制仍有原有能力缺口。

旧宿主若 link 到拆分前的路径，需要由维护者重新指向本目录。本次没有改动该链接或重载正在使用的服务。

HTTP 契约测试在受限沙箱外获准监听临时本机端口后执行；该权限仅用于隔离测试，没有改动宿主服务。语法检查与打包闭包验证不替代用户可见交互验收。
