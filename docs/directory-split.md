# 独立目录说明

日期：2026-11-12。此目录是 NexlOS 插件版的完整源码项目根。可以单独拷走、构建和维护；运行、默认测试及打包不依赖相邻的“nexlos通用版”，也不依赖父目录中的公共文件。

父目录仅用来摆放三个版本：`nexlos通用版`、`nexlos插件版`、`nexlos优盘版`。优盘版按要求保留空目录，本次未创建其实现或说明文件。

办公、界面、配套阅读器与工厂各自位于本项目内；`applications/` 和 `tools/` 是独立保存的配套源码副本。配套代码被放入某个版本，不代表该版本已实现所有宿主能力，也不改变配套代码原有许可。插件公开发行仍应按公开打包脚本排除未整体授权的配套目录。

当前入口与命令见根 `README.md`，本次路径拆分验证见 `split-validation.md`。`project-history/` 保留拆分前组合工程的说明和校验记录，其旧目录路径属于历史事实，不能当作当前安装说明执行。

本版 `import-manifest.json` 已筛选并重映射本版文件路径，同时保留原来源 SHA-256 与拆分前路径。`baseline-manifest.json` 是本版当前文件清单；可在本项目根执行 `python3 scripts/check-source.py --verify-manifest` 核对。拆分前完整清单保存在 `project-history/`，此次没有改写原始来源目录。
